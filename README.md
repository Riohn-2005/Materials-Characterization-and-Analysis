# Materials-Characterization-and-EIS-Analysis


Python scripts for automated data processing, non-linear curve fitting, and visualization of electrochemical and spectroscopic characterization data.

## Repository Structure
* **`EIS/`** – Equivalent circuit modeling and Mott-Schottky capacitance analysis.
* **`GDOES/`** – Glow Discharge Optical Emission Spectroscopy elemental depth-profile visualization.
* **`Raman/`** – Baseline correction and multi-peak deconvolution (Lorentzian/Voigt profiles).
* **`XRD/`** – X-ray diffraction peak indexing, profile fitting, and Scherrer crystallite size calculation.

## Requirements
`numpy`, `scipy`, `pandas`, `matplotlib`
